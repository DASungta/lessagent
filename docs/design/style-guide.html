设计方向：克制、紧凑的工具感

以原版 T3 Code 移动端（Zinc 中性灰 + 深灰主按钮）为准，换成鸿蒙的手势与系统字体。不加装饰，靠层级、留白和对齐来区分信息。

现在看着难受的根源
  • 字号散成 15 档（10–30），层级读不出来
  • 「返回 / 刷新 / 发送」混用纯文字和色块按钮
  • 每条消息都挂着「···」，视觉噪声大
  • 表单用「标签 + 大灰胶囊」上下堆叠，一屏只放得下 4 项
  • 标题栏里的胶囊按钮居中摆放，和标题层级打架
固定下来的五条规则
  • 字号只用 6 档，字重只用 400 / 500 / 600
  • 一屏最多 一个 实心主按钮，其余用图标或文字按钮
  • 标题栏只放图标按钮，文字动作统一放右侧、用主色
  • 设置和表单一律用 分组列表行（左标签、右取值、›）
  • 消息不常驻操作，长按调出菜单
