## 中断点与接手顺序

1. **先核对 B39。** 宿主全量 537/537，终端专项 49/49，签名包已安装。此前版本在 Mate60Pro 上已通过系统选区手柄，精确粘贴三行 `ALPHA`、`BRAVO`、`CHARLIE`。新版已看到选字工具位于正文下方。中断发生在新版选区手势期间，没有最终粘贴回读及最大字号结果。[四张过程图与测试摘要](evidence/r8/batch39/README.md)
2. **接续同一隔离样例。** 最近使用 Terminal 1；源文件在隔离项目 `/tmp/t3-r5-accept-00fcea/data/projects/r5-round2/b39-select-271a.sh`。核对本机服务、该会话及终端仍存在后，从「更多 → 终端 → 文字工具 → 选择文字」进入。长按 ALPHA，拖到 CHARLIE 末尾，选系统「复制」，粘贴回输入框并逐字核对两个换行。只粘贴，保留输入不发送。对默认与系统最大字号分别留图。结束时只关闭本次测试终端、移除该样例并恢复调过的字号。交接时没有执行收尾。
3. **设备常亮。** 上次回读常亮已启用，原自动熄屏时长 600000 ms。后续可用 `python3 scripts/device-keep-awake.py status --device 23E0224122000135` 核实，结束设备测试后可把 `status` 换为 `off`。[设备说明](device-keep-awake.md)
4. **然后按依赖分配工作。** 本机可继续 R6 的重连/大字号和 R7 分享/设置；需要外部条件的 R2 云认证、真实 provider、PR 写入、iOS、折叠/实体键盘单列。视觉验收按页面记录操作入口、构建摘要、普通/特大字号、成功/失败状态与行为回读。[逐项缺口](r6-r8-acceptance.md)

## 构建、验证与代码入口

在工程根目录运行以下命令可以复现宿主检查并生成本机签名调试包。交接时读取了已有结果，没有重跑开发流程。

```sh
node --experimental-strip-types --test tests/*.test.mjs
python3 tests/device-keep-awake.test.py
./scripts/build.sh
shasum -a 256 entry/build/default/outputs/default/entry-default-signed.hap
```

- `scripts/build.sh` 通过 DevEco 内置 Hvigor 构建，默认 `/Applications/DevEco-Studio.app/Contents`，可通过 `DEVECO_HOME` 指定安装位置。项目私有签名材料及设备凭据由接手人另行配置。
- `entry/src/main/ets/pages/Index.ets` 串接路由和页面状态；`components/` 是各功能面板；`protocol/` 负责数据结构和终端解析；`services/` 负责连接、分享、语音等平台能力；`storage/` 管理本机数据。设备权限、分享入口和 Ability 声明见 `entry/src/main/module.json5`。
- B39 主要涉及 `components/TerminalPanel.ets` 和 `protocol/Terminal.ts`，相关用例在 `tests/terminal*.test.mjs`。B38 主要涉及 `services/ShareInbox.ets` 和 `components/ShareImportPanel.ets`。源码基准以交接清单和本机工作区为准。
- [图库](handoff/index.html)可按阶段、批次、文件名和页面搜索，点击缩略图打开原图。正式归档、原版参考、测试中间态和临时缩略图均保留来源。无截图批次保留文字记录入口。截图表明当时屏幕呈现；数据落库、是否发送和权限结果请看对应批次回读。
