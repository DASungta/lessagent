# 首页筛选、排序与恢复

在 Mate60Pro 的隔离环境中，选择没有会话的项目 `pr-read`，旧页面会提示「还没有会话」，只显示新建任务。新版提示「当前筛选没有会话」，可以直接清除筛选。环境筛选也走同一路径，实测清除后原会话重新可见。[旧版](filter-before.jpeg) · [新版](filter-after.jpeg)

排序选择现在会立即显示勾选。实测从最近用户消息切换至创建时间，关闭弹层再打开仍保留选择。系统字号第 5 档下可滚动到底部清除按钮，关闭按钮保持可见。已恢复原排序和字号第 2 档。[特大字号弹层](filter-sheet-large.jpeg)

覆盖安装前选中 `pr-read`，修复前冷启动后会意外变回「所有项目」。原因是绑定环境时将尚未收到的项目列表当成已删除。修复后会保留筛选标识，收到列表后按原项目范围解析。升级安装后实测仍为 `pr-read`，点清除才重新出现 `r5-round2` 的会话。[冷启动结果](filter-cold.jpeg)

特大字号截图还暴露出排序项蓝底深字。调整弹层前景色的继承后，标准字号实机已显示蓝底白字。[修复后排序项](filter-sheet.jpeg)
