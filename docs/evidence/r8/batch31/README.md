# 代码阅读与会话操作

「设置」中搜索「代码」可以调整代码与差异字号，范围 8–18，鸿蒙默认 13。字号与自动换行单独保存在本机，覆盖安装后实测仍为 18、已开启。源码、Git 审阅和 PR Diff 使用同一行组件；聊天中的 Markdown 围栏代码遵循原版移动端的正文样式，终端使用自己的字号。

## 源码与复制

测试仓库中创建了一个五行 TypeScript 文件，第 3 行为 128 个字符，包含缩进及首尾标记。标准字号、关闭换行时，短行和闭合括号靠代码区左侧对齐，横滑长行可见 B31-CODE-END。[原布局](source-before.jpeg) · [左对齐](sourceAligned.jpeg) · [横滑到行尾](sourceScrolled.jpeg)

开启换行、字号调到 18 后，第 3 行折为五个视觉行，只显示一个逻辑行号。选中该行并复制到聊天输入框，与测试文件第 3 行逐字符相同；验收后清空，没有发送消息。[换行结果](sourceWrapped.jpeg) · [系统特大字号、深色](sourceLargeDark.jpeg)

## 会话操作

打开会话右上角「更多」，可直接看到文件与源码、审阅 Diff、Git、拉取请求、终端、浏览器和设备预览。任务控制单独放在下方。普通和特大字号下文件与 Diff 入口均可点按。[以前](session-menu-before.jpeg) · [现在](sessionMenu.jpeg) · [深色特大字号](menuLargeDark.jpeg)
