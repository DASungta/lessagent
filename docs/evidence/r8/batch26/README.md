## 终端滚动区

同尺寸更新现在保留程序设置的滚动范围。隔离终端执行[验收脚本](scroll-region.sh)，进入备用屏，将中间第 2–4 行设为滚动区。向上、向下和换行后，前五行依次是 HEAD、RI、THREE、IND、FOOT。点击适配并再次滚动后，前五行变为 HEAD、THREE、IND、END、FOOT。页头和页尾在两次操作中均保持原位。退出脚本、结束测试终端后，刷新列表为空。[第一次滚动](terminal-region.jpeg) · [适配后](terminal-fit.jpeg)

本批验证了局部滚动与同尺寸适配。完整交互式 TUI、长时间高频输出和外接键盘仍有独立验收项。
