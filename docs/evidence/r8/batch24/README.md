## 会话首页

右上角提供「新任务」，搜索框旁的齿轮进入设置，行尾省略号用于该会话。两项筛选并排。已验证输入不存在的关键词显示空态，点 × 后恢复原会话，点新任务进入所属项目的草稿。设置中搜索「分支命名」能打开工作树默认设置。该页回到前台时先显示只读，随后自行恢复，固定前缀控件 enabled=true。

## 终端

终端页 A− / A+ 可设置 10–24vp，本机默认 14vp。Canvas 字宽与行高用于计算远端终端尺寸。真机新建隔离终端，在 14 和 15 两档分别执行 `stty size`，输出分别为 14 行 40 列、13 行 37 列。离开后重进终端页仍显示 15。已恢复 14，结束测试终端并刷新确认列表为空。[远端输出](terminal-font.jpeg)
