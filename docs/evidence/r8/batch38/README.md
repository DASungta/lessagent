在专用 Mate60Pro 上，打开系统图库中的测试 PNG，点「分享 → T3 Harmony」，然后在应用内点「收到分享 · 审阅并保存草稿」。审阅页显示文件名、大小和目标项目。点「查看图片」即可在附件下方展开本机缩略图。
