## 系统边界

在独立临时构建目录使用[发送夹具](make-sender-fixture.py)，向系统分享面板提供两条纯文字和一条网页链接。在这台手机上，该组合的面板展示和接收端只得到网页链接。[系统面板](systemSheet.jpeg) · [接收结果](received.jpeg)。代码按平台实际返回的记录审阅。多条文字记录的顺序、重复内容、逐项编辑和移除由宿主测试覆盖。ShareKit 的 addRecord/getRecords 契约见[华为 API 文档](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/share-system-share/)。临时构建只改变发送端样例；最终安装包使用真实消息内容。

收件附件只从受限的系统文件或相册 URI 打开，仅按只读权限访问，校验文件类型、大小与内容。支持范围为 UTF‑8 TXT 及 JPEG、PNG、GIF、WebP。单批最多 10 件、50 MiB，暂存队列总量 64 MiB。确认前只在内存暂存，进程退出会丢弃待审阅内容。单项移除释放该项的字节与元数据。跨草稿或跨连接的迟到上传不会覆盖当前附件；取消与部分成功后的手动重试由宿主测试覆盖。

本机草稿保存已上传的服务端附件引用。重启恢复已真机证明，服务端清理过期待认领上传后的恢复不在本批范围内。照片应用的图片授权、真实断网中断/部分成功、云环境和更多 MIME 仍待验收。
