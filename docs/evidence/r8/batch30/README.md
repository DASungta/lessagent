# 双查看者的浏览器控制交接

最终签名 HAP 已安装到 Mate60Pro，SHA-256 为 `7a34683954f25dc360e3bde3815727ed10b7167c881621995237abebcf670c67`。全量宿主回归 480/480 通过，无失败、取消或跳过。

手机和独立的[查看者脚本](viewer.mjs)分别使用自己的媒体会话，附着到隔离 T3 0.1.10 的同一[测试页面](handoff.html)。页面每次实际收到点击都会将序号发送给本机测试服务。最终复验按下面顺序执行。

| 操作 | 手机上的反馈 | 测试服务点击计数 |
|---|---|---|
| 手机释放，第二个查看者取得控制并点击 | 仍显示实时画面，标注「另一查看器正在控制」，「等待释放」禁用 | 8 |
| 手机点击同一按钮 | 手机继续观看；远端未收到点击 | 8 |
| 第二个查看者明确释放，手机点「取得控制」后再点击 | 「你正在控制」，操作按钮变为「释放控制」 | 9 |

[等待释放截图](finalWaiting.jpeg) · [手机接管后](finalControl.jpeg) · [服务端计数与控制代次](readback.json)。另一轮也验证了查看者超时断开后手机可重新取得控制。控制权提示随服务事件更新，连续 JPEG 到达时继续显示。异步手势在控制权转移并返回后不会跨代补发，down/up 竞争由宿主回归覆盖。

独立查看者使用限时授权，已逐次确认撤销本次配对及会话。上述「仅观看」指可操作查看者当前没有持有控制权。只发放只读授权给鸿蒙客户端、Agent 接管以及多环境竞争仍需单独真机验收。

旧版在别人操作时仍显示可点的「取得控制」，点击后服务拒绝抢占。[修改前](otherViewer.jpeg) 最终验收已关闭远端测试页、确认列表为空并停止临时 HTTP 服务。手机留在会话首页。
