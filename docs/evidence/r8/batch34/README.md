# 定时任务模型编辑

Mate60Pro 上从首页齿轮进入「定时任务 → 任务详情 → 编辑 → 更改模型」。未绑定会话的任务可以显式更换 Provider 或模型。普通编辑保留原 modelSelection 和高级选项，明确更换才使用新模型默认选项。绑定会话的任务按该会话当前模型执行，相关限制由宿主回归覆盖。

确认页显示任务标题、启停状态、原模型和新模型。编辑期间点刷新会先询问是否放弃修改，继续编辑保留已选新模型。保存前重新核对环境、模型可用性、权限、任务配置及版本，回读确认结果。[详情改动前](detailBefore.jpeg) · [新详情](detailLarge.jpeg) · [特大字号保存确认](confirmationLarge.jpeg)
